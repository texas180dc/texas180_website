# Client logos

Drop logo image files in **this folder**. The filename must match the `logo`
value in `lib/content.js` exactly.

Any client whose file is missing shows a clean text tile instead — nothing
breaks, and the marquee still looks finished. So you can add logos a few at a
time.

## Format

- **PNG with a transparent background** is ideal. SVG also works (change the
  extension in `content.js` to `.svg`).
- Roughly **400–600px wide**. Bigger just slows the page down; the tiles cap
  the display height at 64px.
- Logos are shown greyscale and turn full colour on hover, so a busy
  multi-colour logo still sits calmly in the row.

**2. The organisation's own press / brand page.** Most nonprofits publish a
media kit with proper transparent PNGs — search `"<org name>" logo press kit`
or `"<org name>" brand assets`. Better quality than anything on Google Images,
and it's the version they want used.

**3. Google Images — last resort.** Results are often low-resolution, out of
date, or the wrong variant. If you use it, filter to **Tools → Size → Large**
and prefer results from the org's own domain.

## A note on permission

Showing a past client's logo to describe work you actually did for them is
normal practice. Some organisations still ask to approve it, and a few have
rules about how their mark is used. Before this goes live, it's worth a quick
email to any client you're unsure about — and remove any that ask you to.
